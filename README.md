# ttykit

personal repo of a script im working on to make tty-only daily driveable on laptop. meant for fedora minimal install (fedora everything netinst without any desktop installed)
NOTE!!! since this is a personal script i dont really care about making it universal. some keys like forward/back may not be present on most laptops (i made this specifically for a tty-only chromebook im using, which has forward/back keys)
